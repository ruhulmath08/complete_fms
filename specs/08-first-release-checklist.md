# First Release Checklist

## Product scope

- [ ] The app supports one farm.
- [ ] There is one owner account.
- [ ] The first version excludes advanced accounting and complex reporting.

## Features

- [ ] Sign up, sign in, and sign out work.
- [ ] The owner can manage basic farm settings.
- [ ] Cow records and milk production work.
- [ ] Poultry groups and layer egg records work.
- [ ] Crop cycles, expenses, harvests, and simple summaries work.
- [ ] Inventory records and stock updates work.
- [ ] General income and expense entries work.

## Before release

- [ ] The web app can complete the main workflows.
- [ ] The mobile app can complete the main workflows.
- [ ] Both apps use the same backend rules and API.
- [ ] The owner can only access their own farm data.
- [ ] Setup instructions explain how to run the backend, web app, and mobile app.
