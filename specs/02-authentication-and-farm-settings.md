# Authentication and Farm Settings

## Purpose

Allow the farm owner to create an account, sign in, and save basic farm details.

## Sign up

The owner can create an account using:

- Profile image
- Full name
- Email address
- Phone number
- Address
- Location (latitude and longitude)
- Password
- Confirm password

All fields are required.

The system must reject invalid email addresses and passwords that do not meet the agreed minimum requirements.

The system must reject duplicate email addresses.

The system must reject duplicate phone numbers.

## Sign in

The owner can sign in using their email address and password.

The owner can sign out.

## Farm settings

The owner can save and edit:

- Profile image
- Full name
- Email address
- Phone number
- Address
- Location (latitude and longitude)

## Acceptance criteria

- A new owner can create an account.
- The owner can sign in and sign out.
- The owner can view and update farm settings.
- A signed-out user cannot access private farm data.
